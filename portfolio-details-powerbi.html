EMR Implementation Project Monitoring Dashboard

This dashboard was created to support monitoring and coordination during EMR implementation projects in a hospital environment. It brings together four reporting views: implementation timeline, manpower monitoring, case monitoring report, and change request monitoring. Project information is integrated from spreadsheet trackers and Azure DevOps to give the implementation team a consolidated view for status reviews and follow-up.

The images shown here are recreated portfolio mockups. Dashboard figures and sample records are illustrative and are not actual hospital or project data.

Dashboard Modules

01. Implementation Timeline

Provides a consolidated view of project phases, planned schedules, milestones, and implementation progress to support timeline reviews and identify activities that need follow-up.

02. Manpower Monitoring

Summarizes manpower assigned to implementation activities so the team can review resource allocation and coordinate support across project phases.

03. Case Monitoring Report

Brings reported cases into a monitoring view so the team can review case status, identify outstanding items, and coordinate follow-up with the relevant stakeholders.

04. Change Request Monitoring

Provides visibility into change requests and their current status, helping the team review requests and keep follow-up actions visible during implementation.

Data Integration & Reporting Flow

  • Spreadsheets: Source trackers used for project timeline, manpower, and supporting monitoring information.
  • Azure DevOps: Project work items and tracking information used for case and change request monitoring.
  • Power BI: Consolidates the selected source data into report pages for project monitoring and status reviews.

The original dashboard connected data from spreadsheets and Azure DevOps. The exact fields, mapping, and refresh behavior depend on the original source setup and are not represented as live connections in these mockups.

How the Dashboard Supports Implementation

  • Review implementation timeline and progress from a consolidated report.
  • Improve visibility of manpower allocation across implementation activities.
  • Keep reported cases visible for review and follow-up.
  • Monitor change request status to support coordination with project stakeholders.
