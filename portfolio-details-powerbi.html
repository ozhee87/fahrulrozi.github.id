Project Progress, Resources & Issue Monitoring

Based on experience creating a Power BI dashboard to support EMR implementation project monitoring in a hospital environment, this portfolio presents an original visual example of the key monitoring views. Project information is consolidated from spreadsheet trackers and Azure DevOps to support implementation coordination, status reviews, and follow-up activities.

Dashboard Modules

01. Implementation Timeline

Review planned implementation phases, key milestones, task progress, and schedule status in a consolidated timeline view.

02. Manpower Monitoring

Review the distribution of implementation roles, allocation by project phase, workload, and resource utilization.

03. Case Monitoring Report

Track reported cases by category, module, priority, and status to support follow-up and issue review.

04. Change Request Monitoring

Track change request types and statuses, including items approved, under review, or rejected.

Data Sources & Integration

  • Spreadsheets: Project trackers and supporting monitoring data.
  • Azure DevOps: Work items and issue / change tracking information.
  • Power BI: Consolidated visuals for progress monitoring and project reviews.

The dashboard brings information from these sources into a single reporting view. The exact refresh and integration setup depends on the source configuration.

Monitoring Objectives

  • Provide a consolidated view of implementation progress and milestones.
  • Improve visibility of manpower allocation and workload.
  • Help prioritize open cases and coordinate follow-up actions.
  • Make change request status easier to review with project stakeholders.

Portfolio note: The visuals on this page are original mockups using illustrative sample data. They do not display actual hospital, company, project, or patient records.
